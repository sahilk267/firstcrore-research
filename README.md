# Business Idea Research Workspace

Static, independent research interface based on a public index of [First Crore](https://ideas.firstcrore.co/) business guides, indexed on 2026-11-08.

## Features
- Search and categorize 120 indexed guide titles
- Save personal notes and scores in your browser's local storage
- Follow source links to guides/archive pages
- Export/reuse the included CSV and JSON inventory

## GitHub Pages deployment
1. Create a **public** GitHub repository, e.g. `firstcrore-research`.
2. Upload `index.html`, `catalog.csv`, `catalog.json`, `.nojekyll`, and `README.md` to its `main` branch at the root.
3. Navigate to **Settings → Pages** and under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**; Save.
4. Site URL should be `https://sahilk267.github.io/firstcrore-research/` once Pages deploys.

## Scope and limitations
This is **not** a full clone of the original site. It catalogues publicly accessible article titles and provides links, without copying full articles. Only five direct article URLs are verified; other entries link to archive pages. Notes/bookmarks are browser-local, not synchronized between devices.

This is an independent, unofficial educational project and is not affiliated with First Crore.
